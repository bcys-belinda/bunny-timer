# 🐰 Bunny Focus Timer

A pastel-pink, cottagecore focus timer starring an orange-and-white Netherland dwarf bunny.

- Animated progress ring with a hopping bunny while you focus
- Editable session length (1–180 min) plus quick presets
- Start / Pause / Reset (Space = start/pause, `R` = reset)
- Carrot tally for finished sessions, confetti + chime on completion
- Boop the bunny! 🌸
- Optional countdown to your next calendar event (edit `js/event.js`)

Open `index.html` in a browser — no build step needed.
